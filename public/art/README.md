# Art assets

The game code is wired for the following files:

- `title-background.webp`
- `sea-music.webp`
- `city-explore.webp`
- `city-noa.webp`
- `city-music.webp`

These generated visual assets are currently kept out of GitHub until the binary-asset workflow is finalized. The UI has CSS fallbacks, so development can continue without them, but the intended presentation uses the real illustrations.
