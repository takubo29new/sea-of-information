## 表示確認

ローカル実ブラウザで、冒頭会話、STGのMEMORY・NOISE・CORRUPTED NODE・敵弾を確認。背景読み込み成功、元解像度、contain適用、コンソールエラーなしを確認した。1280×720、1024×768、390×844で背景がクロップされず表示されることを確認。

確認範囲は背景表示と視認性。難易度・PERFECT達成・全ルート・タッチ操作のQA完了を意味しない。狭幅では背景に上下の余白が大きくなる。既存のチュートリアル枠・Echoの重なりは、別途STG UI調整の候補。

Listening Stageの共通画像参照とクロップ防止はコードで確認したが、今回のSTG通常ルートではListening画面自体の実画面確認は行っていない。
