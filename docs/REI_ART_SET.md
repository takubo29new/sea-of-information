# REI ART SET — Production Specification

この文書はゲーム内で使用するRei立ち絵セットの制作基準。
2026-09-13にユーザー承認されたReiイラストを正式リファレンスとする。

## 目的

Reiは『SEA OF INFORMATION』の顔になる主人公。
単なる設定資料の全身立ち絵ではなく、画面に出た瞬間に魅力が伝わるADV用キャラクターアートを優先する。

## 共通ルール

- 女性、17歳相当
- 黒〜濃紺のロングヘア
- 髪は自然になびき、静止画でも動きを感じる
- 暗いネイビー〜黒のテックウェア系アウター
- 内側に白〜ライトグレー
- 青い小さな発光アクセント / DIVEデバイス
- 細身
- 武装感・軍装感は強くしない
- 過度に性的なポーズや衣装にしない
- キャラデザインを差分ごとに変えない
- 顔立ち、前髪、髪量、服の構成を統一
- UI、文字、ロゴ、枠、背景を素材へ焼き込まない
- 実装用は透明背景PNGを基本とする
- 最低目標解像度: 長辺 2000px以上

## 立ち絵スタイル

「全身が見えること」より「魅力的に見えること」を優先してよい。
膝上〜太腿上、3/4身、半身なども可。
シーンに応じて以下を使い分ける。

### 01 Neutral
- 基本のRei
- やや斜め向き
- 視線はプレイヤー方向か少し外す
- 髪が軽くなびく
- 表情は静かで少し好奇心がある
- 棒立ちにしない

推奨ファイル:
`public/art/production/characters/rei/rei-neutral.png`

### 02 Thinking
- 指先を顎や首まわりへ添える
- Dr. Reiとの共通癖を暗示できる
- 眉をわずかに寄せる
- 深刻すぎず、観察・推理している表情

推奨ファイル:
`public/art/production/characters/rei/rei-thinking.png`

### 03 Surprised
- 目を少し見開く
- 体をわずかに引く、または視線を強く対象へ向ける
- 大げさな漫画的リアクションにしない

推奨ファイル:
`public/art/production/characters/rei/rei-surprised.png`

### 04 Serious
- 終盤や重要判断用
- 視線が強い
- 姿勢は少し前向き
- 悲壮感より「自分で選ぶ」意志を感じさせる

推奨ファイル:
`public/art/production/characters/rei/rei-serious.png`

## ゲーム実装ルール

- REIが話している時は原則Rei立ち絵を表示
- SYSTEMや環境描写では必要に応じて非表示
- NoaやBITが話している時は話者側を優先
- 同じ画面に2人出す場合、会話話者を明るく、非話者を少し抑える方式を検討
- 会話枠やObjectiveと重ならない位置へ配置
- 画面サイズに合わせて過度に拡大しない

## 禁止事項

- キャラシートをそのままゲーム素材にする
- 小さい元絵を単純アップスケールして最終素材扱いする
- 完成ゲーム画面を画像として生成してUIごと使う
- 差分ごとに髪型・顔・衣装が別人化する
- 白髪、銀髪へ変える
- ReiをDr. Rei本人やクローンとして表現する
