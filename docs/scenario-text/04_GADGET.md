```text
AREA 02
GADGET AREA
```

> 次の世界は、朝の街とは正反対だった。巨大な歯車と搬送路が、暗闇の中で停止している。

SYSTEM:
```text
GADGET AREA / MAINTENANCE ZONE
```

REI:
> 今度は工場か。……動いてないけど。
> こういう場所は分かりやすいな。止まってるなら、動かせばいい。

調査:
- 停止した案内板
- 機械区画へ進む
- 条件未達: 工場のリズムを観察する

POWER 12% / CONVEYOR OFFLINE / SERVICE UNIT STANDBY

## gadget-machinery

ナレーション:
> 動かせそうなのは三つ。電源、歯車、天井クレーン。

REI:
> 一つずつ戻せば、奥まで行けそうだ。
> 押して、回して、どかす。今までで一番分かりやすい。

調査 / 復旧:
- 電源をつなぎ直す
- 歯車の印を合わせる
- クレーンをどかす
- 奥の整備室へ
- 条件未達: 復旧した機械の音を確認する

### 電源

ナレーション:
> 電源をつなぎ直すと、床下を青白い光が走った。

SYSTEM:
```text
AUXILIARY POWER / ONLINE
```

REI:
> よし。まず一個。ちゃんと光ると安心するな。

UI:
```text
POWER / 電源接続
左から順に3つのスイッチを入れて、電源をつなぐ。
AUX / 予備
BUS / 中継
MAIN / 主電源
順番が違う — 最初から
1 / 3 接続済み
```

### 歯車

ナレーション:
> 歯車の印が揃う。低い駆動音が、曲のリズムに重なった。

REI:
> ……ちょっと気持ちいいな、これ。
> ずっと回してたいけど、先行くか。

UI:
```text
GEAR / 歯車合わせ
光る印が上の基準線に合うよう、3つの歯車を回す。
目標: 左 90° / 中央 180° / 右 270°
```

### クレーン

ナレーション:
> クレーンが軋みながら横へ動き、塞がれていた整備室が現れた。

SYSTEM:
```text
MAINTENANCE PATH / OPEN
```

REI:
> 道が開いた。機械って、動くと急に素直だな。

UI:
```text
CRANE / 通路を空ける
クレーンを黄色い退避場所まで動かす。
← 左へ
右へ →
現在: ベイ 1 / 目標: ベイ 4
```

進捗UI:
```text
RESTORE
止まった機械を3つ動かす
POWER
GEAR
CRANE
COMPLETE — 奥の整備室へ進める
```
