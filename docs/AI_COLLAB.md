# AI並行開発ルール

このプロジェクトでは ChatGPT / Claude / Astra を並行利用するため、同時作業による競合を避ける。

## 役割

- **ChatGPT**: メイン実装、ゲーム構造、演出、アート統合、統合作業
- **Claude**: コードレビューとレビュー指摘の修正
- **Astra**: 実ブラウザQA、プレイヤー視点の操作・表示・進行確認

## 現在のブランチ運用

- `dev`: 現在の統合先。Claudeのレビュー修正はこちらへ入れてよい。
- `chatgpt/v06-art`: ChatGPTが既存章の実イラスト統合・演出基盤を並行開発する作業ブランチ。
- `main`: 安定版のみ。直接作業しない。

## 重要

Claudeがレビュー指摘を修正している間、ChatGPTは原則として `dev` の同じファイルを直接編集しない。

Claude側の修正が完了したら、`chatgpt/v06-art` を最新 `dev` に追従させ、競合を確認したうえで統合する。

## Claudeに修正を任せてよい範囲

以下はClaudeに直接修正してもらって問題ない。

- 明確な進行不能
- React effect / listener / timer の不具合
- TypeScriptエラー
- save/loadの安全性
- 二重クリックや二重遷移
- Audio lifecycleのバグ
- テスト追加
- 小〜中規模の保守性改善

ただし以下は勝手に変更しない。

- ストーリー設定
- シーン順
- 曲の役割
- Listening Phaseを短縮・撤去する判断
- キャラクター設定
- 大規模なアーキテクチャ置換
- UI/演出コンセプトの全面変更

これらが必要に見える場合は、修正せず提案として報告する。

## Astra

Astraはコード変更を主目的にせず、実ブラウザ上で再現手順・期待値・実際の挙動を記録する。
