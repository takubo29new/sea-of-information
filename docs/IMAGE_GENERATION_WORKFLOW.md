# IMAGE GENERATION WORKFLOW

SEA OF INFORMATION の画像制作では、ゲーム実装チャットと画像生成チャットを分離する。

## なぜ分離するか
長い実装セッションでは、過去に生成した「タイトル画面」「UI付き完成画面」「キャラクター設定シート」の文脈を画像生成側が強く拾い、単独キャラクターや純背景を指定しても同じ構成へ戻ることがある。

そのため、正式アートは **新しい画像生成専用セッション** で制作する。

---

## 共通ルール
- 1セッション = 1種類の素材
- キャラクターと背景を同じセッションで生成しない
- UI、ロゴ、文字、メニュー、会話枠、設定シート、コラージュを禁止
- 1回の生成で1枚だけ
- キャラクター差分は、最初に承認された基準画像を添付して編集として生成する
- 新規描き起こしを繰り返さず、可能な限り基準画像の編集を使う
- 差分間で顔、髪、衣装、体格、年齢感を維持する
- ランタイム採用前に解像度・透明背景・輪郭・UI混入を確認する

# 背景専用セッション

キャラクター画像を一切添付しない。

## 共通開始指示
```text
このチャットはゲーム「SEA OF INFORMATION」の背景美術制作専用です。
人物・UI・文字・ロゴ・メニュー・会話枠は絶対に描かないでください。
16:9の純粋な背景美術だけを1枚ずつ制作します。
```

## City of Dawn
```text
16:9、人物なし。
朝の柔らかな光に包まれた小さな未来都市の広場。
探索ADV用背景として、画面内に以下が自然に視認できる構図：
- 時計塔
- 少年が転ぶことになる石畳の一角
- 鳥が集まる屋根または電線
- 小さなパン屋

暖かな朝色。生活感があり、ループ前は安心できる街に見える。
同時に、少しだけ整いすぎた不自然さを感じる。
UI・文字・ラベル・キャラクターは禁止。
```

## 採用チェック
1. 単独素材か
2. 焼き込み文字がないか
3. UIがないか
4. キャラクターの顔が正式Reiと一致しているか
5. 透明背景が本物のalphaか
6. 実表示サイズの2倍以上の解像度があるか
7. ADV画面で魅力があるか

基準を満たしたものだけ `data/artAssets.ts` で approved にする。
