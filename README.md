# SEA OF INFORMATION

Original browser game project combining music, visual storytelling, exploration, and mystery.

## Development status

Current working version: **v0.4**

Implemented so far:
- Title / NEW GAME / CONTINUE
- Sea of information prologue
- City of Dawn chapter through the first night
- Data-driven Scene/Event architecture
- Autosave and settings foundation
- Music Archive foundation
- Listening Phase UI: important scenes deliberately switch into a full-screen music-player presentation, then fade back into gameplay when the next progression point unlocks
- Initial key-visual / character-art integration

Next milestone:
- Gadget Area
- BIT introduction
- Environmental machinery puzzle
- `IDENTITY MATCH 99.7% / WELCOME BACK` reveal

## Design principle

The soundtrack is not treated as background music. Major tracks are designed as playable scenes: visuals, interactions, dialogue timing, and progression are synchronized to the music so players have time to actually experience and remember each track.
